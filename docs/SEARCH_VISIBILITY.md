# Search visibility

All 33 HTML pages, including the portfolio and legacy blog, carry `noindex, nofollow, noimageindex`. Only metadata was added; original page content and Git history remain.

Crawling is deliberately not blocked by robots.txt, so search engines can observe noindex. No authentication or access restriction is introduced. Anyone with the URL, or access to the public GitHub repository, can still read the material. Previously indexed results disappear only after a crawler processes the directive; removal is not immediate.

References: https://developers.google.com/search/docs/crawling-indexing/block-indexing and https://developers.google.com/search/docs/crawling-indexing/robots-meta-tag
